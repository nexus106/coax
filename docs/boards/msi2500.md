# DTV02-1T-U（MSi2500 + MSi001）

USB ID `1df7:2500` を `msi2500` バックエンドで扱います。
別名は `dtv02-1t-u` です。
地上デジタル ISDB-T 用のフロントエンドを1個公開します。
復調処理は既存の IC 名による配置に合わせて `internal/coaxd/demod/msi2500` に置いています。
MSi2500 自体は ADC と USB の IC で、ここではその IQ 出力に対応するソフトウェア復調を実装しています。
USB 制御から復調、誤り訂正まで Go で処理するため、GNU Radio、Python、libmirisdr、CGo は実行時に不要です。

## 使い方

既存の `list`、`tune`、`scan` コマンドを使います。
`coax` と `coaxd` を同じディレクトリに置き、アンテナを接続します。
ソースからビルドする場合は `go.mod` が指定する Go 1.26 以降が必要です。

```sh
CGO_ENABLED=0 go build -o coax ./cmd/coax
CGO_ENABLED=0 go build -o coaxd ./cmd/coaxd
./coax list
./coax tune --system ISDBT --ch 24 --gain 15dB -o ch24.ts
./coax scan --system ISDBT --ch 24 --gain 15dB -o ch24.json
```

`24` は物理チャンネル番号の例です。
複数台ある場合は、`coax list` に表示される ID を `--tuner` に指定します。
開く際に USB ファームウェアをリセットするため、USB アドレスは変わることがあります。
ポートに基づくチューナー ID を使うと、この変化の影響を避けられます。

利得は `0dB` から `85dB` で、初期値は `15dB` です。
強い信号では利得を上げると ADC が飽和するため、受信が改善するとは限りません。
UHF の設定範囲は 330 MHz 以上、960 MHz 未満です。
VHF、衛星放送、DVB-T は対象外です。

出力は放送の TS で、スクランブル解除は行いません。
このバックエンドでは本体のカードスロットを公開しません。
カード機能については既存の [カードリーダーと PC/SC ソケットの説明](../reference/card-reader.md) を参照してください。

## 復調の範囲

Mode 1/2/3、GI 1/4、1/8、1/16、1/32 を探索します。
TMCC のパリティを検証してから、QPSK、16QAM、64QAM と符号化率 1/2、2/3、3/4、5/6、7/8 を処理します。
DQPSK など、検証済み TMCC が示す未対応設定はエラーにします。
A 層と B 層を含む全有効層を復号し、層間の時間インターリーブ遅延をそろえて TS を出力します。
送信側で取り除かれたヌルパケットの元の配置は再現しないため、出力は可変ビットレートです。
パケット内の PCR とペイロードは保持します。

実録による検証は、macOS / Apple M4、Mode 3、GI 1/8、A 層 QPSK 2/3、B 層 64QAM 3/4 で行っています。
他のモードの同期や、変調、誤り訂正の各処理は、合成信号と標準に基づく部品単位のテストで確認しています。
すべての組み合わせを実機で受信した結果ではありません。
実機検証済み OS は macOS です。
機器の消失、置き換え、USB アドレス変更は擬似レジストリによる回帰テストで確認しています。
実機の USB 抜き差しは試験していません。

## オフライン検証

録音と放送 TS はリポジトリに含めません。
ローカルの IQ は、8,126,984 複素サンプル/秒のリトルエンディアン signed16 I/Q 交互形式で指定できます。

```sh
COAX_ISDBT_IQ=/path/to/local.cs16 go test ./internal/coaxd/demod/msi2500 -run TestRecordedTS -v
```

Apple M4 の約9.919秒の録音で、復調処理5回の中央値は7.025秒でした。
先頭1回を除いた中央値は7.034秒で、録音時間の約0.71倍です。
これは特定の録音と測定機での結果です。
保存 IQ から PAT、PMT、NIT、SDT の CRC が正常な TS を取得し、独立した復調器の出力とも照合しています。
実機では既存の `coax scan` で放送の番組情報を取得することを確認しています。
