# DTV02-1T-U Go Native Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Go だけで DTV02-1T-U の受信、coax 統合、B-CAS 復号を行い、録音の80%以下の処理時間を目標に速度を検証する。

**Architecture:** USB、OS 非依存の ISDB-T 復調、クライアント側 B25 を別パッケージにする。
USB と B25 と FEC は共有ファイルを持たない独立した担当範囲として並行実装できる。
復調とバックエンドの結合は主担当が行う。

**Tech Stack:** Go 1.26以降、既存 usbio/boardkit、macOS IOKit/PCSC.framework、ARIB STD-B31/B25。

**Spec:** `docs/superpowers/specs/2026-10-31-msi2500-native-design.md`（ユーザー承認済み）。

## Global Constraints

- `CGO_ENABLED=0` を維持する。
- 外部の GNU Radio、libmirisdr、libarib25、Python を実行時依存にしない。
- gr-isdbt の GPL-3.0 C++ 実装を翻訳、複写して取り込まない。
- 計算手順は公開規格に基づき書き起こし、各ファイルに出典と SPDX を付ける。
- 実カードの鍵、番号、録音、放送映像を Git に含めない。
- 初期の実機保証は現在の Apple Silicon Mac に限定し、他OSの既存ビルドを維持する。
- GitHub の変更は作業ブランチに限定する。
- `gh` コマンドは最初からサンドボックス外で実行する。

## Review Focus

- 切断やキャンセル後にUSB取得処理が残らず、再度機器を取得できること（Task 2/6）。
- カード切断時にスクランブルビットだけを消した未復号データを返さないこと（Task 1）。
- TMCC未検証、無信号、サンプル欠落時に古いロック状態を保持しないこと（Task 4/6）。
- A/B層のSIとPCR、PID順序が保たれ、正常受信に見える不完全TSを完成扱いにしないこと（Task 5/6）。
- 生存経路の切り捨てとRS訂正不能を隠さず、誤り訂正の単なる往復テストで正しさを主張しないこと（Task 3/5）。

### Task 3: ISDB-T FEC

**Files:** Create `internal/coaxd/demod/isdbt/fec/` only.
**Interfaces:** `NewViterbi(rate int) (*Viterbi,error)` where rates 0..4 mean 1/2,2/3,3/4,5/6,7/8; `(*Viterbi).Decode(dst,symbols []byte) []byte` consumes punctured 0/1 coded bits, appends decoded bytes to dst, and preserves state across calls; `Reset()`. `DecodeRS(word []byte) (corrected int,err error)` mutates exactly 204 bytes to a valid RS(204,188) word. `NewByteDeinterleaver() *ByteDeinterleaver`, `Push(dst,src []byte) []byte`, `Reset()`.

- [ ] Read STD-B31 outer/inner coding and interleaving sections, without copying GPL-3.0 implementation.
- [ ] Add independent known vectors and failing tests for puncturing, Viterbi traceback across chunk boundaries, 8-byte RS correction and 9-byte failure, byte deinterleaver delay and reset.
- [ ] Observe red with `go test ./internal/coaxd/demod/isdbt/fec`.
- [ ] Implement fixed 64-state Viterbi and GF(256) RS with polynomial 0x11d, shortened RS(255,239) to (204,188), roots alpha^0..alpha^15. Implement the 12-branch inverse convolutional interleaver specified by STD-B31.
- [ ] Run correctness tests, benchmark allocations and throughput, and race test state-independent decoder instances.
- [ ] Commit only this package and report measured throughput plus startup/traceback byte latency.

### Task 4: Synchronization, FFT and TMCC

**Interfaces:** `New(Config) (*Decoder,error)` and `(*Decoder).PushIQ(samples []complex64,discontinuity bool) ([]byte,error)` is the intended end-to-end interface; `Status()` reports verified lock and measurements. Intermediate interfaces are internal implementation decisions.

- [ ] Add failing FFT impulse/tone tests, CP correlation for Mode 1/2/3 and each GI, frequency-offset and sample-loss tests, TMCC syndrome and parameter decoding tests.

- [ ] Implement equalization and fine frequency/timing tracking with bounded buffers and no per-sample allocation.

- [ ] Verify saved IQ detects the same Mode3/GI1/8 and A/B settings as the reference; synthesize alternate modes and GI cases.
- [ ] Benchmark and commit tested synchronization components.
